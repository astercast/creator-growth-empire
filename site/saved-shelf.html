Saved Shelf

Your saved tools, held as one shelf — the favourites pattern the hub never had: save any tool from its own page and it waits here, in the order you saved it, one tap back and one tap to remove, plus one copyable list for the whole shelf. The catalogue is the hub's own committed tool records; the saved set is yours alone, stored only in this browser, never sent anywhere. There is deliberately no most-saved ranking — that signal needs usage collected across visitors, and this site collects none. A saved tool the catalogue no longer lists is counted apart as stale and never rendered as a tool; a shelf with nothing saved yet and a shelf whose saves are all stale are different states, and the shelf says which.

SAVED SHELF Your saved tools, in the order you saved them — stored only in this browser.

The hub holds every tool in the manual, and a working creator uses a handful of them over and over. This page is the shelf for that handful: open any tool, tap “Save to your shelf” in its briefing panel, and it waits for you here — one tap back to each tool, one tap to remove it, and one copyable list for the whole shelf.

The catalogue behind this page is the hub's own tool list (All Tools). Your saves live only in this browser's local storage — there is no account, nothing is sent anywhere, and clearing this browser's site data clears the shelf. There is deliberately no most-saved ranking here: that signal needs usage collected across visitors, and this site collects none, so no popularity order is invented in its place.
